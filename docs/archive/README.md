# Archive — Pre-CLAUDE.md Design Documents

These four documents (AI_Build_Charter_v1.1, MotorDeals_AI_OS_3.1, MASTER_INDEX, setup_motordealos.bat) are the original design for MotorDeals AI OS: a 9-agent factory (orchestrator, content generator, compliance, publisher, lead router, follow-up executor, chat, voice, approval gate) with a week-1-through-4 rollout of the full marketing/lead-automation system.

CLAUDE.md (repo root) is the current, authoritative project constitution and supersedes these documents for all v1 (Phase 1–3) build decisions — it deliberately scopes down to a smaller, single-agent, human-gated build: modern stack → public site → manual lead inbox → SEO → AutoFunds/workbook imports → AI chat, with voice, social auto-posting, and follow-up automation explicitly deferred to Phase 4+.

The 9-agent architecture described here is NOT rejected — it's the reference design for Phase 4+ once Phase 1–3 is live and proven. Do not execute setup_motordealos.bat; it scaffolds the old file tree and conflicts with the current SKILLS.md build recipes.
